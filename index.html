A QUICK START

How to use the simulator

Follow a machine's decisions, one small step at a time.

01

Choose a machine

Start with a finite automaton, then explore a Turing machine or a pushdown automaton. Each one comes with a short explanation and an example string.

02

Enter a string

Use only symbols from the machine's input alphabet. The simulator checks your string before execution so you can spot invalid symbols right away.

03

Watch it work

Run continuously or advance one transition at a time. Follow the active state, read head, tape or stack, and transition history.

04

Understand the result

A machine accepts when its formal acceptance condition is met, rejects when it reaches a reject state, and may halt if no transition exists.

✳
What is an automaton?

An automaton is a mathematical model that reads or processes input according to a set of rules. Different types of machines have different computational power: finite automata have states, pushdown automata add a stack, and Turing machines can read and write on an unbounded tape.
